# Adel Electric quantity takeoff

Adel-takeoff is an electrical quantity takeoff engine for Adel Electric, LLC. Plans go in. A counted Excel workbook and a marked-up PDF come out.

The build order is in [docs/ROADMAP.md](docs/ROADMAP.md).

The quantity engine is the draft on branch `cursor/estimating-takeoff-v1-8b7a` ([pull request #1](https://github.com/Nagejo/adel-takeoff/pull/1)). This default branch does not contain that code yet. Statuses in the roadmap were read from that branch.
